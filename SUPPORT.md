# Support

Team Spaces is a community-maintained open-source project. Community support is
best effort and does not include guaranteed response or resolution times.

## Where to ask

- Use a bug report for reproducible defects in the current source.
- Use a feature request for product proposals and significant design changes.
- Use a repository discussion, when enabled, for setup questions and general
  implementation advice.
- Consult the README and `docs/` before opening a request.

Include the commit or version, deployment mode, relevant configuration with
secrets removed, exact symptoms, and the smallest useful log excerpt.

Never post credentials, tokens, private URLs, customer data, or production
exports. Report suspected vulnerabilities privately according to
[SECURITY.md](SECURITY.md).

Forks and modified deployments are welcome, but their maintainers are
responsible for their changes and operation. This repository does not promise
commercial support, managed hosting, migration services, or an uptime SLA.
