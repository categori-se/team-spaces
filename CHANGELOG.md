# Changelog

Significant changes to Team Spaces will be recorded here. The project intends
to follow [Semantic Versioning](https://semver.org/) once tagged releases begin.

## Unreleased

### Added

- Open-source contribution, conduct, security, support, governance, trademark,
  roadmap, and third-party notice documentation.
- GitHub issue forms, pull-request guidance, and dependency-update automation.
- A generic, demand-priced AWS community profile with installation-owned
  Cognito, generated private buckets, one on-demand DynamoDB table, finite
  logs, optional PITR/operations/public-demo layers, and synthesis guardrails.
- Versioned DynamoDB record export/import with dry-run validation, bounded
  inputs, empty-target protection, and explicit identity/attachment recovery
  boundaries.
- Generated third-party license notices distributed with the web build.

### Changed

- A hosted deployment is an explicit operator profile rather than
  the default deployment path.
- Public documentation now distinguishes no paid idle compute from a
  guaranteed zero AWS bill and identifies every retained-data or optional
  operational cost dimension.

No tagged public release has been published yet.
